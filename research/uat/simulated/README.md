# Simulated UAT

Use this folder for task-based synthetic user testing.

Rules:

- Label every note as simulated.
- Name the artifact being evaluated.
- Use concrete tasks, not broad opinions.
- Include the synthetic user or panelist lens.
- Record failure points and required proof.
- Do not promote synthetic findings as real UXR.

Recommended filename:

```text
<yyyy-mm-dd>-<flow>-simulated-uat.md
```
