# Observed UAT

Use this folder for consent-safe notes from real users attempting concrete
tasks.

Rules:

- Record consent level.
- Use participant labels or aliases, not private handles.
- Do not commit private contact details, raw DMs, recordings, or sensitive
  participant data without explicit permission.
- Separate observed behavior from interpretation.
- Record exact points of hesitation, misunderstanding, abandonment, or trust
  break.

Recommended filename:

```text
<yyyy-mm-dd>-<flow>-observed-uat.md
```

Start from:

- `research/templates/real-uat-observation.md`
- `research/templates/real-interview-note.md`
