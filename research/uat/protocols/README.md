# UAT Protocols

Use this folder for reusable task scripts and evaluation rubrics.

Keep protocols small and flow-specific. A good protocol should state the
artifact, participant segment, starting state, task, success criteria, and what
the researcher may or may not explain.

Initial protocol targets:

- `public-realm-preview.md`: public realm preview and request/invite posture.
- `first-face-onboarding.md`: account, membership, first face, application,
  claim, and reserve.
- `wanted-to-plotting-handoff.md`: wanted hook, prospective interest, plotting
  room, and scene start.
- Writer Desk to scene reply
- application review
- Studio launch checklist
