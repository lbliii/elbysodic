# Elbysodic Handbook

Elbysodic is a roleplay-native studio layer for directors and writers running
living play-by-post realms. This handbook keeps the product direction,
technical boundaries, and operating practices together.

## Handbook sections

- [Product](product/) — product strategy, roleplay-native vocabulary, writer
  journeys, and realm direction.
- [Architecture](architecture/) — tenant, identity, privacy, data, and rendered
  surface contracts.
- [Operations](operations/) — production setup, deployment checks, and operator
  runbooks.

Contributor-only agent instructions remain in the repository and are not part
of the reader-facing handbook navigation or search index.
