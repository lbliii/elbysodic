# Seed art direction

Seed imagery uses one cinematic, grounded key-art treatment per realm. Hero
images are wide establishing scenes with room for interface copy; location
covers are atmospheric place shots; character and member avatars are square,
naturalistic portraits. The shared image prompts asked for no lettering, logos,
watermarks, or UI. Realm-specific light, palette, wardrobe, and setting cues
carry across all three asset types so each realm reads as one world.

| Realm | Visual direction |
| --- | --- |
| X-Men Apocalypse | Mutant-crisis thriller: winter blue, charcoal, emergency red, institutional steel, and signal-lit snow. |
| Afterlight Accord | Post-conflict fantasy: ash, rust, fractured gold, hard dusk, and treaty relics at a border. |
| Brightline | Awards-season backstage drama: velvet black, champagne gold, camera glare, and immaculate event spaces. |
| Crownfall | Epic court fantasy: slate stone, deep wine, worn gold, heraldic cloth, and divided power. |
| HP Universe | Candlelit gothic academy mystery: old stone, dark wood, book dust, warm brass, and restrained green. |
| Jurassic Park Universe | Tropical survival thriller: rain-heavy jungle, electric fence blue, amber alerts, and industrial utility light. |
| RL NYC | Contemporary city drama: wet pavement, subway blue, sodium amber, dense windows, and lived-in streets. |
| RL Small Town | Contemporary ensemble drama: late-summer dusk, storefront warmth, civic spaces, lake water, and familiar roads. |
| Harbor Society | Coastal prestige drama: midnight water, ivory stone, warm gala windows, and quiet old-money formality. |
| Nocturne Row | Urban gothic fantasy: ink-dark streets, bruised plum, cold moonlight, rain, and breached treaty motifs. |
| Signal Creek | Analog paranormal mystery: evergreen mountains, receiver amber, midnight blue, fog, and impossible radio signals. |
| Emberhouse | Ritual dark fantasy: soot-black halls, ember red, bronze, stone ranks, and trial-fire light. |
| Gaslight Ward | Victorian occult mystery: gaslit sepia, wet cobbles, blue-green shadow, fog, and period tailoring. |
| Wayfarer Station | Orbital sci-fi mystery: deep navy, cool station light, amber status lamps, worn metal, and isolated crew spaces. |

The prompt set used ImageGen to create 14 realm heroes, 22 location covers, 93
character portraits, and 12 member portraits. Portrait sheets were cropped into
individual JPEG seed assets. Seed reruns upgrade the previous generated SVG
defaults to the new art while leaving user-edited media in place.
