# Elbysodic Circle Terminals Brand Kit

Date: 2026-05-10

This folder contains the focused brand treatment for the selected Elbysodic
logo direction.

## Core Idea

```text
o --   opening post
o -    reply beat
o ---  continuing scene
```

The mark is intentionally compact:

- circles = faces, roster, public authorship
- bars = posts, threads, scenes, continuity
- long/short/long progression = a thread unfolding
- cyan/magenta/yellow = Technicolor-style color records
- black key = studio precision and online clarity

## Assets

- `mark-primary.svg`: default brand mark.
- `mark-small.svg`: favicon/app-icon optimized version.
- `favicon.svg`: explicit 64x64 small-size favicon source.
- `mark-one-color-dark.svg`: one-color dark-container version.
- `mark-one-color-light.svg`: one-color light-container version.
- `mark-bare-on-light.svg`: bare symbol for light surfaces.
- `mark-bare-on-dark.svg`: bare symbol for dark surfaces.
- `lockup-horizontal.svg`: primary horizontal lockup.
- `lockup-compact.svg`: compact header lockup.
- `lockup-stacked.svg`: stacked presentation/social lockup.
- `brand-treatment.html`: focused review and usage page.

## Usage Guidance

Use `mark-primary.svg` for general brand contexts and product surfaces where
the mark appears at 32px or larger.

Use `mark-small.svg` or `favicon.svg` below 32px. The terminals and bars are
slightly heavier so the thread structure survives small rasterization.

Use the bare marks only where the background is controlled and contrast is
obvious. The rounded black-key container is safer for user-generated or
community-themed contexts.

The lockups use system type as a spacing study. Before production launch,
redraw or finalize the Elbysodic wordmark so the type has the same intentional
quality as the symbol.
